✅ 已经装好了，返回到应用即可全屏使用。

安卓 Chrome / Edge

  1. 用 Chrome 打开应用（不要用微信里打开）
  2. 点右上角 ⋮（三个点）
  3. 选 「添加到主屏幕」 或 「安装应用」
  4. 点「添加」，桌面就会出现图标

iPhone Safari

  1. 必须用 Safari 打开（微信内不支持安装）
  2. 点底部中间的 分享按钮（方框带向上箭头）
  3. 往下滑，选 「添加到主屏幕」
  4. 点右上角「添加」
如果找不到「添加到主屏幕」：确认是不是用 Safari 打开的，微信、QQ、钉钉内的浏览器都不支持。

提示 为什么值得装

  1. 全屏运行，没有地址栏，和 App 一样
  2. 桌面有独立图标，一点就开
  3. 首次打开后会缓存，断网也能抄表
  4. 不占存储空间，不经过应用商店
